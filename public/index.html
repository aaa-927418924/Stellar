今日は何を学ぼう？

分からない問題や単元を送ると、触って学べる教材を作ります。

OpenCode が教材を生成します。出典や解説は教材内で確認できます。

教材プレビュー

HTMLを保存
教材内の「学習／問題モード」を切り替えて試せます。

設定

既定はMuse Spark 1.3 Freeです。一覧にない場合は下の入力欄に provider/model 形式で入力してください。

OpenCode CLIが見つかりません

教材の生成にはOpenCode CLIが必要です。次のコマンドでインストールしてから、アプリを再起動してください。

npm install -g opencode-ai

別の場所にある場合は STUDY_OPENCODE_EXE に実行ファイルの絶対パスを設定します。チャットの閲覧と保存はこのまま使えます。
