# Stellar

学びたい内容をチャットで伝えると、OpenCode CLI を使ってインタラクティブな単一 HTML 教材を作るローカルアプリです。教材を画面右側で操作しながら、その内容をチャットで質問できます。

## 起動

Windows では [start-stellar.cmd](start-stellar.cmd) をダブルクリックしてください。Node.js 20 以上、OpenCode CLI、OpenCode で利用できるモデルの認証が必要です。OpenCode CLIが見つからない場合は起動時に案内ダイアログが表示されます（`npm install -g opencode-ai` で導入できます）。起動後、Edge のアプリウィンドウが開きます。黒いコンソールを閉じるとローカルサーバーも終了します。

ブラウザーのウィンドウだけを閉じても、コンソールが開いている間は生成が続きます。再度ランチャーを開くと、実行中のアプリへ接続します。終了時は起動情報を破棄します。古い起動情報が残っていても、次回起動時に生存確認のうえ上書きします。

## デスクトップ版（フレームレス窓）

```powershell
npm run build:exe
npm run build:window
```

`dist/Stellar/Stellar.exe` をダブルクリックで起動します。タイトルバーのない専用ウィンドウ（WebView2）が開き、右上のボタンで最小化・最大化・閉じるを操作できます。バックエンド（`Stellar.Server.exe`、Node.js同梱）は自動で起動・終了します。.NET 8 Desktop ランタイム、OpenCode CLI、モデルの認証が必要です。特別な実行ファイルを使う場合は `STUDY_OPENCODE_EXE` を設定します。

exe版の会話と教材は、以前の履歴を引き続き使うため `%APPDATA%\StudyApp\data` に保存されます（開発時の `npm start` はリポジトリ内の `data/` を使うため、履歴は共有されません）。

```powershell
cd 'C:\Users\PC_User\Documents\Codex Projects\Study App'
npm start
```

既定モデルはMuse Spark 1.3 Freeです。左下の設定からモデル一覧で変更できます。一覧にない場合は `provider/model` 形式で手入力もできます。OpenCode 側の認証やモデル設定はこのアプリでは変更しません。

## 使い方

1. 新しいチャットに「中学2年生向けに一次関数を教えて」のように入力し、「教材を作る」で送信します。ファイルは5件まで添付できます（画像はサムネイル表示、クリックで拡大）。HTML不要で質問だけしたい場合は「質問する」を選びます（質問用チャットは質問専用になります）。
2. 右側の HTML 教材で、学習モードと問題モードを切り替えます。3. 「教材について質問」を選んで聞くと、教材の内容を踏まえて回答します。「○○の問題を作って」と頼むとチャット内に問題が出題され、その場で解答・正誤判定と記録ができます。
4. 内容を変えたいときは「教材を更新」を選んで指示します。
5. 「HTMLを保存」から、ブラウザーで単独で開ける教材ファイルを保存できます。
6. 質問用チャットでは「教材作成」ボタンで会話を整理し、新規チャットの入力欄に教材作成プロンプトが自動入力されます（自動送信はされません）。
7. 左下の「ライブラリ」から作成済みのHTML教材・問題セットを一覧できます。問題はメッセージ単位で保存され、挑戦回数が表示されます。開くと最初から解き直せ、履歴は追加記録されます。
8. 「今日の復習」では保存済みの問題の正誤や経過日数をもとに、優先度の高い問題を自動で選びます。準備後にAIによる復習内容の説明を確認してから解答を始めます。「AI生成の類題を含める」をオフにすると新しい類題は作らず、保存済み問題だけを出題します。既存問題がない場合は開始できません。復習での解答は履歴に保存されますが、ライブラリの挑戦回数は増えません。
9. 「今日の復習」は暦日ごとに1セッションで、完了後はその日に再生成できません。翌日は新しい復習を準備できます。完了後に開放される「もっと復習」は何回でも追加で利用できます。AI類題の設定は同じチェックボックスを使います。追加復習の結果も保存しますが、短時間の繰り返しで翌日以降の自動選択が変わらないよう、今日の復習の優先度計算からは除外します。
10. チャット一覧の項目を右クリックすると、サイドバーへのピン留め・解除や削除を選べます。ピン留めしたチャットは一覧の上部にまとまって表示されます。

生成はバックグラウンドで続きます。チャットを切り替えても進行し、開いたままなら画面が自動更新されます。「生成の経過」は生成中の進行表示で、完了後は非表示になります。モデルが思考本文を公開しない場合は、確認できた経過だけが記録されます。任意の時点で「生成を中止」を押せます。アプリのサーバーを終了すると進行中の処理は中断扱いになります。

会話と教材は `data/` に保存され、再起動後も残ります。`data/` は Git の対象外です。新規生成や更新で出典の正しさまで機械的に保証できないため、重要な学習内容は参考資料も確認してください。

アプリ本体はこのPCで動きます。入力文と添付画像は、選択したOpenCodeモデルの提供先へ送られます。オフラインAIではありません。

## 設計

- Node.js 標準ライブラリの HTTP サーバーが `127.0.0.1` のランダムポートのみで待ち受け、OpenCode CLI の `run --format json` を起動します。
- 教材の指示は [server/prompts.js](server/prompts.js) に同梱し、添付された `interactive-study/SKILL.md` の教材要件をアプリ向けに整理しています。
- 生成 HTML は外部通信を禁止する CSP と、`allow-scripts` だけを許可した iframe でプレビューします。保存した HTML はアプリから独立した教材として利用できます。
- AI 呼び出しには出力専用の `study` エージェントを使います。教材ファイルへの書き込みはアプリ側で行います。OpenCode 側のツール権限はユーザー設定に従います。
- フロントエンドに外部ライブラリやビルド工程はありません。

## 開発・確認

```powershell
npm test
```

ブラウザーを自動で開かずにサーバーだけ起動するには、`STUDY_NO_BROWSER=1` を設定します。特別な OpenCode 実行ファイルを使う場合は `STUDY_OPENCODE_EXE` にその実行ファイルの絶対パスを設定します。
